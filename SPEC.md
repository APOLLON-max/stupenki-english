# Ступеньки English — спецификация

Веб-тренажёр английского для взрослых: с нуля и для тех, кто уже знает язык. Уровни от A0 до C2.
Опубликован как артефакт Claude: https://claude.ai/artifact/1a1Rd8gjf7843Qc9411Qfd

## 1. Что умеет продукт

1. **Адаптивный тест уровня.** 15 вопросов, по 5 на слова, грамматику и чтение. Уровни по шкале CEFR: A0, A1, A2, B1, B2, C1, C2, отдельно для каждого навыка. Первые два шага по навыку идут через уровень, дальше по одному, поэтому за 5 вопросов тест добирается до C2.
2. **Карта знаний.** 63 темы: 22 темы слов, 30 тем грамматики, 11 разделов чтения. У каждой темы своя оценка усвоения от 0 до 1. На главной показаны «Получается хорошо» и «Над чем работаем».
3. **Тренировка дня.** 10 заданий: около 20% повторения, 60% самых слабых тем и 20% нового (на текущем уровне). Ошибки возвращаются в конце тренировки в более простом формате. Когда все темы уровня освоены, навык переходит на следующий уровень.
4. **11 игровых форматов:** угадай картинку, что значит, что это, найди на картинке, послушай и выбери, собери слово, найди пары, вставь слово, собери фразу, правда или нет, прочитай и ответь.
5. **Озвучка.** Все английские слова, фразы и тексты заранее записаны (голос Samantha, macOS).
6. **Мотивация.** Очки опыта, серия дней подряд, уровни в виде камней: бронза, серебро, золото, изумруд, сапфир, рубин, бриллиант.

## 2. Методика

| Принцип | Как реализован |
|---|---|
| Адаптивная диагностика (как в тестах Oxford и Cambridge) | Ступенчатый тест: верный ответ — вопрос сложнее, ошибка — проще |
| Активное вспоминание (retrieval practice) | Все задания требуют вспомнить, а не перечитать |
| Интервальные повторения, система Лейтнера | 5 коробок, интервалы 1, 2, 4, 7 и 15 дней. Ошибка возвращает карточку в первую коробку, повтор через 10 минут |
| От узнавания к воспроизведению | Формат слова зависит от коробки: выбор картинки → поиск на картинке или на слух → сборка по буквам. С уровня B2 основной формат — перевод («Что значит?») |
| Фокус на слабом | Около 60% тренировки — самые слабые темы |
| Чередование (interleaving) | Задания разных форматов и тем идут вперемешку, один формат не повторяется два раза подряд |

Источники: [Spaced Repetition and Retrieval Practice](https://www.researchgate.net/publication/397538205), [Leitner System](https://my-senpai.com/insights/exploring-leitner-system.html), [ERIC: computer-based spaced repetition](https://files.eric.ed.gov/fulltext/EJ1143520.pdf).

## 3. Устройство

```
index.html            вёрстка и стили (тёмный liquid glass)
config.js             адрес и публичный ключ Supabase (пусто — только локальное хранение)
data.js               весь контент: уровни, темы, слова, грамматика, тексты
app.js                логика: модель ученика, Лейтнер, подбор заданий, игры, экраны, синхронизация
audio/words.json      озвучка слов и коротких фраз (mp3 в base64)
audio/sentences.json  озвучка предложений и текстов
supabase/schema.sql   таблица и функции базы данных
tools/build-audio.js  скрипт, который озвучивает контент из data.js
```

- **Хостинг:** GitHub Pages, статический сайт без сборки.
- **Прогресс** всегда пишется в `localStorage` (ключ `stupenki-v1`). Если в `config.js` задан Supabase и человек вошёл по имени и PIN, прогресс дополнительно синхронизируется с облаком (см. раздел 3.1).
- **Как добавить контент:** дописать данные в `data.js`, затем выполнить `node tools/build-audio.js`. Нужны macOS и ffmpeg.
- **Звук** играет через Web Audio API из заранее записанных клипов. Голос браузера (Web Speech API) используется только как запасной вариант.
- **Локальный запуск:** нужен любой статический сервер, например `python3 -m http.server`. При открытии `index.html` как файла озвучка не загрузится.

### 3.1. Облачное сохранение (временное решение)

Задача — два человека, у каждого свой прогресс, доступный с любого устройства. Сделано максимально просто:

- **Supabase, бесплатный тариф.** Одна таблица `progress`: имя, хэш PIN-кода (bcrypt), весь прогресс одним JSON, время обновления.
- **Вход:** имя и PIN из 4–12 цифр. Если имени нет в базе, профиль создаётся автоматически. Можно продолжить без входа, тогда всё хранится только на этом устройстве.
- **Защита:** RLS включён без политик, поэтому таблицу нельзя прочитать напрямую даже с публичным ключом. Доступ только через функции `load_progress` и `save_progress`, которые сверяют PIN на стороне базы. Лимит — 5 профилей.
- **Синхронизация:** сохранение через 1,5 с после изменения, а также сразу при сворачивании вкладки. При открытии страницы и возврате на неё подтягивается облачная версия, если она новее (сравнение по `savedAt`). Конфликты не сливаются: побеждает последняя запись.
- **Индикатор в шапке:** зелёная точка — сохранено, голубая — сохраняем, красная — нет связи. Двойное нажатие на имя — выход.

**Если проект будет развиваться, базу нужно пересмотреть.** Это решение рассчитано на двух человек. Варианты на будущее:
- Supabase Auth (вход по ссылке из письма, Google или Apple) вместо имени и PIN, с политиками RLS на пользователя;
- хранение прогресса по сущностям (карточки, темы, сессии) вместо одного JSON — для аналитики и слияния изменений с разных устройств;
- другая база или свой бэкенд (Firebase, PocketBase, Postgres и API), если понадобятся платежи, кабинет учителя или нагрузка.

Смена базы затрагивает только три функции в `app.js`: `rpc()`, `cloudLoad()` и `cloudSave()`, плюс файл `supabase/schema.sql`. Остальной код работает с объектом прогресса `S` и о базе не знает.

## 4. Решённые проблемы

| Проблема | Решение |
|---|---|
| Кнопка озвучки нажималась, но звука не было. В приложении Claude и в артефакте у голоса браузера нет голосов | Весь английский контент заранее озвучен (480 клипов) и проигрывается через Web Audio |
| Кракозябры вместо русского текста при локальном запуске | Добавлен `<meta charset="utf-8">` |
| Класс `.reading` конфликтовал с цветовым маркером навыка «Чтение» | Блок текста переименован в `.passage` |
| Дизайн не нравился | Переделан в стиле Apple liquid glass по референсам: стекло, светящиеся кольца прогресса, камни уровней, неоновые кнопки-пилюли |
| В «Собери фразу» и «Собери слово» ошибку можно было исправить, только убрав все плитки | Добавлено перетаскивание мышью и пальцем: плитку можно вставить в любое место или переставить внутри строки. Нажатие по-прежнему работает |
| Во время теста нельзя было выйти в меню | Кнопка «← Меню» с подтверждением «Выйти?». Главное меню доступно и без пройденного теста, на нём висит плашка с предложением пройти тест |
| Максимальный уровень был B1 | Добавлены B2, C1, C2: 7 тем слов (включая идиомы), 11 тем грамматики, 6 текстов, новый формат «Что значит?» |
| Генератор выдавал неграмотные фразы вроде «This is a water» | Неисчисляемые существительные исключены из генератора |
| Серия дней считалась по UTC и сбивалась вечером | Дата считается по местному времени |
| Карточка в прогрессе могла ссылаться на удалённое из `data.js` слово и ломать тренировку | Такие карточки пропускаются при повторении (`validKey`) |
| Сайт открывался только внутри Claude, прогресс не переносился между устройствами | Хостинг на GitHub Pages и облачное сохранение в Supabase по имени и PIN (раздел 3.1) |
| На телефоне шапка не помещалась | На узких экранах название скрывается, остаются значки |

## 5. Потенциальные проблемы и риски

**Данные и прогресс**
- Без входа прогресс живёт только в одном браузере и теряется при очистке данных сайта.
- Вход по имени и PIN — простая защита. PIN хранится на устройстве открытым текстом, подобрать 4-значный PIN перебором реально: ограничения попыток нет.
- Публичный ключ Supabase лежит в открытом репозитории. Это допустимо (доступ закрыт функциями с PIN), но любой может создать до 5 профилей и занять лимит.
- Если заниматься одновременно на двух устройствах, прогресс одного из них перезапишется (побеждает последняя запись).
- Бесплатный проект Supabase ставится на паузу после недели без активности, и его нужно будить вручную в панели Supabase.
- Если переименовать слово, его прогресс по Лейтнеру сбрасывается: ключ карточки — это само английское слово.

**Методика и контент**
- На уровнях B2–C2 сейчас по 2 текста и по 3–4 темы грамматики. Опытный ученик быстро исчерпает материал, и задания начнут повторяться.
- Тест состоит из 15 вопросов, у каждого 2–3 варианта ответа. Шанс угадать высокий, поэтому уровень может быть завышен на одну ступень.
- Эмодзи для абстрактных слов и идиом (C1–C2) передают смысл условно. Задания «угадай картинку» на этих уровнях скорее развлекают, чем учат.
- Нет навыков говорения и письма, только узнавание и сборка.
- Уровень навыка может только расти. Если человек долго не занимался, уровень не снижается.

**Техника**
- Озвучка весит около 4,3 МБ и загружается целиком при открытии. На медленном мобильном интернете первые секунды звука может не быть.
- Голос macOS Samantha звучит синтетически. Для C1–C2 нужен более естественный голос.
- `backdrop-filter` и анимированный фон нагружают слабые телефоны.
- Выбрана только тёмная тема, светлой нет.
- Перетаскивание проверено мышью в Chromium. На iOS Safari и Android ещё не проверялось.

## 6. Планы на будущее

Формат запуска пока не решён: сначала доводим MVP, потом решаем, будет ли это личный инструмент, публичный сайт или платный продукт.

### 6.1. Аккаунты и облачный прогресс
- Первый шаг сделан: имя и PIN, Supabase (раздел 3.1).
- Если проект пойдёт дальше — полноценные аккаунты (email, Google, Apple) и **пересмотр базы данных** по вариантам из раздела 3.1.
- Нужна будет политика хранения персональных данных.

### 6.2. Больше контента для B2–C2
- По 6–8 текстов на уровень вместо двух. Жанры: новости, письма, эссе, диалоги.
- Новые темы грамматики: артикли в продвинутом употреблении, причастные обороты, фразовые глаголы, коллокации.
- Словарные задания без эмодзи для абстрактной лексики: синонимы, выбор слова по контексту, толкование на английском.
- Более естественный голос для озвучки длинных текстов.
- Более длинный или двухэтапный тест для точной оценки уровней выше B1.

### 6.3. Говорение и письмо
- **Произношение:** запись ответа с микрофона и распознавание речи с оценкой. Внутри артефакта Claude микрофон недоступен, поэтому это требует отдельного сайта.
- **Письмо:** короткие ответы и мини-эссе с проверкой ИИ (грамматика, лексика, оценка по CEFR).
- Новые навыки «Говорение» и «Письмо» на карте знаний, со своими уровнями.
